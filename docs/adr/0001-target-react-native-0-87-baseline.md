# 1. Target React Native 0.87.x Baseline and Modern Architecture

Date: 2026-08-31
Status: Accepted

## Context
`react-native-template-ts-plus` was originally maintained through React Native `0.70.7` (React 18.1.0). Since then:
- React Native 0.76 made New Architecture (Fabric, TurboModules) default.
- React Native 0.82 made New Architecture mandatory / exclusive.
- React Native 0.87.1 is the current stable release on npm.

In Phase 0, a scaffold-first rebuild strategy was selected to replace `template/` with a clean CLI baseline rather than doing an error-prone in-place upgrade.

## Decision
1. **Target Baseline**: Target React Native `0.87.x` (current stable: `0.87.1`) as the foundation for the template modernization.
2. **Architecture**: Target New Architecture exclusively. All retained libraries must support Fabric/TurboModules.
3. **Native Languages**: Use Kotlin (Android) and Swift (iOS) app entrypoints as generated by the modern `@react-native-community/cli`.
4. **Environment**: Enforce Node 20+ / Node 22 LTS, and Zulu JDK 17 for Android build toolchains.

## Consequences
- Native project files (`template/android`, `template/ios`) will be rebuilt cleanly from modern CLI templates.
- Legacy configuration files (e.g. `metro-react-native-babel-preset`, `@react-native-community/eslint-config`, Flipper CocoaPods workarounds) will be removed in favor of `@react-native/babel-preset`, `@react-native/eslint-config`, and modern preset packages.
- Dependencies that do not support RN 0.87 or New Architecture will be updated or replaced with maintained equivalents.
